# 章节资料包 · 通用规则（每章动笔必读，随资料包一起粘贴）

## A. 作品设定（30 秒了解）

- 《ENDER LILIES · 终焉之雨》同人视觉小说，忠实重述原作主线。
- 主角**莉莉**是哑巴，全程无台词；玩家视角的"我"心声每章不超过 2 页、每页一句。
- **费林**（黑之骑士）承担全部对话与引导，是叙述担当。
- 每章 = 一个区域：抵达 → 探索 → 秽鬼群像（哀鸣引文）→ Boss 战 → 净化 →
  记忆回放 → 亡语 → 拾取石板 → 启程（下一章钩子）。
- **台词原文只能从本章资料包的引用池逐字搬运**（含引号「」、标点、省略号，
  一字不改）；你的工作是补足场景描写、费林的引导转场，把引文串成可读的视觉小说。
- 页面以空行分隔，一块 = 一页；页面类型见源稿格式文档。

## B. 硬性规则

- 台词原文从引用池**逐字搬运**，禁止改写、润色、拼接改字；群像哀鸣用旁白引文呈现
  （不给说话人），有名有姓的记忆角色才用 `角色id(表情)「…」` 台词页。
- 亡语的标记写在台词行尾 」之后：`gerold(serious)「秽鬼……」（亡语）`——编译器会剥离
  标记，不会显示在游戏文本里。
- **格式铁律**：`@bg` / `@cg` / `@music` / `@set`（独立使用时）必须**独立成块**——
  指令行与正文之间空一行，`##小标题` 也必须独占一块，否则编译报错或内容被丢弃；
  `@reaction` 例外，必须与它作用的台词**同块**。
- Boss 段一条指令两个参数：`@music boss_<area>_intro boss_<area>_outro`
  （**不存在**独立的 `@music_outro` 指令）；净化记忆段 `@music <area>_quiet`。
- 选项下缩进的 `@set` / `@when` 只允许使用本章资料包白名单里的键；如需新 flag，
  在交付说明中提出，由合入侧登记后才能引用。
- 台词页每页至多 2~3 条引文（同一节拍的连续句可合并），转折处必须拆页；
  记忆独白可 3~4 条一页；群像哀鸣每个角色一页；新写连接页每页 20~60 字；战斗页用短句。
- 章节页数以本章资料包提纲为准；引用密集时以样章节奏为准（06 章实际 53 页）。
- 每章必须包含：`@set cleared_<area>=true`（净化后）与 `@set relic_<n>=true`（遗物页，
  拾取该章石板文书），以及指向下一章的启程钩子。

## C. 交付格式

- **只输出一个 markdown 代码块**，内容 = 本章 `story-src/*.md` 全文（含 frontmatter，
  按本章资料包给出的 frontmatter 照抄）。
- 引用的页块内加注释行 `//引-N`（或 `//费-1` 等），供合入侧核对。
- 文件末尾追加 `//自检：` 注释：总页数、各引文编号是否已用、@set 清单。
- 不要输出解释文字，不要尝试运行任何命令（你没有终端；编译与测试由合入侧执行
  并回传结果）。
