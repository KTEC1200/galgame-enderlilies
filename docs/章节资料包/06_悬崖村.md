# 任务：撰写《ENDER LILIES · 终焉之雨》同人视觉小说「悬崖村」一章的场景源稿

你将得到三个附件：**源稿格式文档**（语法严格照做）、**两个样章**
（03_净忆 = 记忆回放/亡语样板；05_启程 = 选项/遗物/启程样板）。你的产出是
一个可直接编译的 `story-src/06_悬崖村.md` 全文。

## A. 作品设定（30 秒了解）

- 主角**莉莉**是哑巴，全程无台词；玩家视角的"我"心声每章不超过 2 页、每页一句。
- **费林**（黑之骑士）承担全部对话与引导，是本章的叙述担当。
- 每章 = 一个区域：抵达 → 探索 → 秽鬼群像（哀鸣引文）→ Boss 战 → 净化 →
  记忆回放 → 亡语 → 拾取石板 → 启程。
- **台词原文只能从本资料 C 节引用池逐字搬运**（含引号「」、标点、省略号，一字不改）；
  你的工作是补足场景描写、费林的引导转场，把引文串成可读的视觉小说。
- 页面以空行分隔，一块 = 一页；页面类型见源稿格式文档。

- 莉莉与费林离开白教区，冒雨前往悬崖村；莉莉已戴上白巫女护身符。
- 确定状态：西丽德已净化、第一枚石板已解读（flag `sield_purified=true`、`relic_1=true`）。
  其余前章 flag 因玩家选择而异，**本章禁止引用**。

  （拾取第二枚石板文书）；启程页指向下一站魔女森林。
