# 终焉之雨 · 全流程攻略（A/B/C 三结局通法）

> 对应版本 v0.5.0。本作单主线 + 终章三选一，全篇唯一真正影响内容的分支只有
> 12 章的「寝宫探索」，其余选项均为演出口味差。石板漏拿可在终章「追忆」补齐。

## 0. 先记住三条规则

1. **石板（relic_1~8）是 C 结局的钥匙**：01 与 06~11 章净化后主线必得，
   只有 relic_8（12 章都城寝宫）是可选探索——漏了任何一枚，都能在
   **终章边境之泉的「追忆」页补齐**（选中后返回追忆页，可连补多枚）。
2. **三个结局在终章最后一页三选一**，选完即收束，互不影响：
   - 「净化她」→ 结局 A（无条件）
   - 「放弃净化，走向深渊最深处」→ 结局 B（无条件）
   - 「唤醒古代咒术，修复守护宝具」→ 结局 C（**仅当八枚石板齐全才显示**）
3. 01 章的两个口味选项（观察 / 跟随、道谢 / 点头）与结局无关，随意选。

## 3. C 结局完整通法（全收集路线）

1. 01~11 章：正常推进即可，每章净化后自动入手对应石板（页面有明确演出提示）。
2. **12 章选「深入寝宫，回应那声呼唤」**，取得第八枚石板后继续主线。
3. 终章「追忆」页若仍显示某枚石板选项，说明有遗漏——逐个「追忆」直至全部持有
   （该页只在石板缺失时显示对应选项，集齐后页面只剩「迈向泉水深处」）。
4. 「迈向泉水深处」→ 剧情推进 → 最终选项中会出现第三项
   「唤醒古代咒术，修复守护宝具」→ 选择，见证 C 结局。

## 4. 「故意漏石板」测试路线（验收用）

- 12 章直接选「直接前往王座大殿」（缺 relic_8）→ 终章追忆页会显示
  「追忆都城寝宫的石板」→ 补齐 → 依旧可进 C。
- 更极端：全程无视也行——01 与 06~11 的石板是主线页自动 @set，想漏只能漏
  relic_8；在终章追忆补上后 C 选项即出现。
- 石板不齐时 C 选项**隐藏**（不是置灰），只剩 A/B 两项——这是设计而非 bug。

## 5. 分支树与回溯

- 「剧情分支树」（标题菜单或 Esc 菜单）里蓝色卡片 = 已走过的场景，点击可**回溯到该场景开头**重来。
- 想补做 12 章寝宫探索：回溯到 12 章卡片即可，选另一条路。
- 回溯不影响已解锁图库与已读记录。
