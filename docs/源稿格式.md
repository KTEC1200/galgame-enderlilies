# 源稿格式 v1

剧情写在 `story-src/*.md`，由 `tools/build_story.py` 编译成 `data/story.json` +
`flowchart.json` + `art_index.json`。**写剧本只碰 story-src，永远不改手写 JSON。**

```bash
python tools/build_story.py    # 在 game/ 目录执行；有错误则不写任何产物
```

## 文件组织

- 一个场景一个文件，按文件名排序即游玩顺序：`01_苏醒.md` `02_钟楼.md` …
- `00_设定.md` 是全局配置（不产生剧情）：`cast_names`（角色 id→显示名）、
  `initial_flags`（全部 flag 的初始值）
- 节点 id = 文件 frontmatter 的 `id` + 标签/自增序号，如 `c01_look_around`

## 场景 frontmatter

```markdown
---
id: c01              # 节点 id 前缀（必填）
chapter: 第一章       # 左上角章节名
title: 长眠者之堂     # 场景标题
bg: black            # 进入时的背景（可省）
music: boss_church_intro boss_church_outro   # 进入时的 BGM，第二个词 = Outro（可省）
cast: lily/normal, knight/normal             # 初始登台（可省）
---
```

## 正文语法（空行分页，一块 = 一页）

| 写法 | 含义 |
|---|---|
| 普通文本行 | 旁白页（多行合并为一页） |
| `knight「台词」` | 角色台词页 |
| `knight(soft)「台词」` | 台词 + 说话人表情 |
| `#标签` | 给下一页命名（供跳转引用） |
| `##小标题` | 改场景标题（左上角） |
| `* 选项文本 -> 目标` | 选项；`目标` = 同文件标签 / `文件id#标签` / 完整节点 id |
| `  @set k=v`（缩进在选项下） | 选择后写入的 flag |
| `-> 目标`（独立成块） | 无条件跳转 |
| `\| when: k=v \| 文本` | 条件变体：覆盖本页文本；写成 `knight(soft)「…」` 可连说话人一起换 |
| `@bg id` / `@music cue [outro]` / `@cg id` / `@cg off` | 独立成块 = 换场节点 |
| `@cast a/expr, b/expr` | 换人（整体替换）；`@cast + c/expr` 加人；`@cast - c` 退场 |
| `@set k=v` | 独立成块 = 换场时写 flag；写在页面块内 = 该页即写 |
| `@when k=v,k!=v,k>=n,k<=n` | 独立成块 = 条件作用于下一页；写在页面块首 = 作用于本页 |
| `@reaction lily/worried` | 本页内其他角色的表情变化 |
| `// 注释` | 编译时忽略 |

值类型：`true`/`false`/整数/带引号字符串。**所有 @when/@set 用到的 flag 必须在
`00_设定.md` 的 initial_flags 声明**（未声明但有过赋值的会自动补 false 并告警；
从未赋值的直接报错）。

## 编译器自动做的事

- **校验**：跳转/选项目标存在、角色 id 与表情名合法、BGM cue 已登记、
  背景与 CG 文件存在（缺文件只警告）、flag 未初始化、不可达节点
- **Boss 曲接力**：`music` 填 `_intro` 曲且目录里登记了配对 Outro 时自动补 `music_outro`
- **美术需求清单**（`art_index.json`）：模拟运行时逐页渲染状态（含"说话人自动登台"），
  每页产出 `background/x`、`sprite/角色/表情`、`cg/x` 键——这就是你的**美术生产清单**
- **flowchart.json**：每个源稿文件 = 分支树的一个块，含页面数与跨场景连线

## 工作流建议

1. 改源稿 → `python tools/build_story.py` → 0 错误
2. `godot --headless --path . -- --smoke` → SMOKE PASS
3. 打开 Godot 编辑器实玩检查演出节奏
