## 0. 使用方法（先读）

1. 管线不变：l0veyou.com（GPT Image 2.5 满血版）→ 上传**单张参考图** + 整条提示词。
   ⚠️ 参考图一次只能传一张（多张会"上传失败"）；传前把设定集页转成 JPG 可更稳。
2. **参考图 = 每条提示词标注的设定集页**：`C:\Users\27025\Desktop\EnderLilies\设定集图片\<页码>.png`
3. 立绘选**竖版 2:3（1024×1536）**；背景/CG/标题选**横版 16:9（1536×1024）**。
4. 出图没有透明通道：立绘是**纯白底**，交回合入侧批量抠图、裁边、`normalize_sprites.py` 规范化后覆盖 `assets/` 同名文件。
5. 同一角色先出 normal（设定集页参考）→ 满意后**拿这张 normal 当底图**连出所有差分（只改表情），一致性最好。
6. 背景想叠"原作氛围"时，可把设定集场景页与 `UI\RestPointTextures\T_MapImg_*.png` 氛围条**左右拼成一张图**再上传（拼图即可，别传两张）。

## 2. 两条铁律（每条提示词已内置）

- **防糊**：高分辨率成品、线条锐利、细节丰富；无模糊、无噪点、无扫描阴影/折痕/反光。
- **去排版**：只提取参考页里的**角色与场景设计本身**；忽略页面上的文字说明、装饰花边框、
  多图分格与页码——输出单张干净完整的成品图。

## 8. 验收入库流程（与既有管线一致）

1. 生成图发回合入侧 → 批量抠图（立绘白底转透明）、裁边；
2. 立绘跑 `python tools/normalize_sprites.py`（幂等规范化）；
3. 覆盖 `assets/` 同名文件（背景 `assets/backgrounds/<id>.png`、立绘 `assets/sprites/<角色>/<表情>.png`、CG `assets/cg/<id>.png`、标题 `assets/key_visual.png`）；
4. `Godot --path . -- --shots` / `--cast-shots` 截图目检；纯图片替换不影响 SMOKE 结论，但仍建议跑一遍。
