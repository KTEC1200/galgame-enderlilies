## 0. 使用方法（先读）

1. 管线：l0veyou.com（GPT Image 2.5 满血版）→ 上传**单张参考图** + 整条提示词（每条已完整，复制一次即可）。
   ⚠️ 参考图一次只能传一张（多张会"上传失败"）；设定集页传前转 JPG 更稳。
2. **参考图 = 每条标题标注的设定集页**：`C:\Users\27025\Desktop\EnderLilies\设定集图片\<页码>.png`
3. 立绘选**竖版 2:3（1024×1536）**；背景/CG 选**横版 16:9（1536×1024）**。
4. 出图没有透明通道：立绘是**纯白底**，生成后把图交回合入侧，批量抠图 → 裁边 →
   `python tools/normalize_sprites.py` 规范化 → 覆盖 `assets/` 同名文件。
5. 同一角色只需出 1 张 normal；**重制覆盖前先把现有 `assets/sprites/` 备份**。
6. 背景想叠"原作氛围"时，可把设定集场景页与 `UI\RestPointTextures\T_MapImg_*.png`
   氛围条**左右拼成一张图**再上传（不要传两张）。

## 5. 入库流程

1. 生成图发回合入侧 → 立绘批量抠图（白底转透明）、裁边；
2. 立绘跑 `python tools/normalize_sprites.py`（幂等规范化）；
3. 覆盖 `assets/` 同名文件（立绘 `assets/sprites/<角色>/normal.png`、背景 `assets/backgrounds/<id>.png`、CG `assets/cg/<id>.png`）；
4. `Godot --path . -- --shots` / `--cast-shots` 截图目检。

## 6. 关于"不做表情差分"的说明

剧情源稿中引用过的表情（如 lily/soft、knight/worried 等）在对应文件缺失时，引擎会
**自动回退到该角色的 normal**（回退机制已内建，不会有占位图或报错），因此：
- 不需要改剧情、不需要改代码、不需要跑编译器；
- SMOKE 测试结论不受影响；
- 将来若想补差分，随时按文件名放入即可生效。
