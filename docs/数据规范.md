# 数据规范 v1

引擎（`Main.gd`）不包含任何剧情；全部内容来自 `data/story.json`。
改剧情 = 改数据，永远不改代码。本文档是剧情编译器（阶段 2）要产出的目标格式。

## 1. story.json 顶层结构

```json
{
  "version": "el-vn-1",          // 存档兼容标记，改结构时必须升级
  "title": "ENDER LILIES · 终焉之雨（样章）",
  "release_version": "0.1.0",
  "cast_names": { "lily": "莉莉", ... },   // 角色 id → 显示名（台词人名牌用）
  "initial_flags": { "curious": false, ... }, // 所有会被 set/when 用到的 flag 都要在此初始化
  "nodes": [ ... ]               // 扁平节点数组，顺序即默认推进顺序
}
```

## 2. 节点类型（只有三种）

### line —— 一页对话（默认类型，`"type":"line"` 可省略）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 全局唯一。约定 `c{章}_l{序号}` |
| `speaker` | ✅ | 角色 id（见 §3）；旁白用 `""`；主角心声用 `"我"` |
| `text` | ✅ | 正文 |
| `expression` | | 说话人的表情覆盖 |
| `reactions` | | `{角色id: 表情}`，非说话人的表情变化 |
| `variants` | | 条件文本变体，第一条满足 `when` 的生效，可覆盖 text/speaker/expression/reactions |
| `choices` | | `[{label, next, set?}]`，出现时停下等选择 |
| `set` | | 页面即写入的 flag |
| `when` | | 条件不满足则整页跳过 |
| `cg` | | 单页临时 CG 覆盖（不写则沿用最近一次 stage 的 cg） |

### stage —— 换场（不显示，直接生效）

| 字段 | 说明 |
|---|---|
| `bg` | 背景 id（缺省沿用上一个） |
| `date` / `title` | 章节名 / 场景名（左上角标题栏） |
| `cast` | 登场列表 `[{"id","expression","form"?}]`，整体替换当前舞台 |
| `cg` | 事件 CG id（空串关闭；显示 CG 时隐藏立绘） |
| `music` | BGM cue（见 §5） |
| `music_outro` | Boss 曲 Outro cue（与 `music` 一起接力，见 §5） |
| `set` | 换场时写入的 flag |

### jump —— 无条件跳转

`{"id": "...", "type": "jump", "next": "目标节点id"}`

## 3. 条件系统 `when`

```json
{"when": {"met_knight": true}}                 // 相等
{"when": {"chapter": {"gte": 2, "lte": 4}}}    // 数值比较
{"when": [{"a": true}, {"b": {"neq": 1}}]}     // 数组 = 全部满足(AND)
```

flag 是字符串/数字/布尔混合的字典，由 `set`（stage/line/choices 均可携带）写入。
**所有用到的 flag 必须出现在 `initial_flags` 里**（缺省为 null，与 false 不相等）。

### 文件路径

```
assets/backgrounds/<bg>.png          1280x720

```

## 5. BGM cue（由 `tools/build_music_catalog.py` 从仓库 music/ 自动生成）

| cue | 用途 | cue | 用途 |
|---|---|---|---|
| `title` | 标题画面 | `boss_<area>_intro` | Boss 战起（不循环） |
| `opening` | 序章 | `boss_<area>_outro` | Boss 战续/余波（循环） |
| `<area>` | 区域日常（循环） | `boss_final_*` | 最终战（Mother） |
| `<area>_quiet` | Save/回忆氛围变体 | `awakening` / `abyss` | 觉醒 / 深渊 |

`<area>` ∈ church / village / forest / cave(地下墓穴) / swamp(禁区) /
oubliette(地牢) / castle(都城) / fort(堡垒)。

**Boss 接力**：stage 节点写 `"music": "boss_church_intro", "music_outro": "boss_church_outro"`，
Intro 播完自动交叉淡入 Outro。若同一 Boss 曲对已在 `pairs` 登记，可省略 `music_outro`。

## 6. 存档格式

- 自动续档：`user://el_resume.json`（每页覆盖写）
- 手动存档：`user://el_slot_N.json`

内容：`{version, node, flags, cast, bg, cg, chapter, title, music, finished, time}`。
读档要求 `version` 匹配且 `node` 仍存在于当前 story.json，否则拒绝（提示版本不匹配）。

## 7. 美术缺失降级

缺图时引擎自动用「按文件名哈希着色的占位图」顶替并向控制台输出一次错误，
游戏不中断。`tools/make_placeholders.py` 生成的是**正式规格**的占位图，
正式美术直接覆盖同名文件即可。
