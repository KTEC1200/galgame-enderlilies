# 剧情结构规划（改编总纲）

> 本文档是**结构规划**，不是剧本。台词创作的唯一权威来源是仓库根目录的
> `sources/ENDER LILIES 文本集.md`（玩家原话与亡语，原样引用、不得改写）；
> 设定细节以 wiki（`entities/` `events/` `concepts/`）为准。
> 白教区样章（story-src/01~05）是格式与节奏的样板——动笔前先通读它。

## 一、改编定位

**忠实重述**：《ENDER LILIES》主线做成剧情向视觉小说。叙事骨架沿用原作——

- 主角莉莉（哑巴，台词只存在于回忆中），引导者费林（黑之骑士，全篇的叙述与对话担当）
- 每章 = 一个区域：抵达 → 探索 → 遭遇秽鬼群像（哀鸣引文）→ Boss（守护者/骑士的残响）→ 净化 → **记忆回放** → **亡语**（高潮，原文引用）→ 拾取遗物/石板 → 启程（下一章钩子）
- 三结局：A 净化 / B 深渊 / C 尾声

**立项原则：群像角色不做立绘。** 有名有姓的记忆角色才需要立绘（约 10 人）；村民、
商人等群像全部用旁白引文呈现（配 `<area>_quiet` 氛围曲）。美术门槛压到最低。

## 三、结局路由（编译器条件系统直接支持）

flag 约定（写入各章的 `@set`，并在 `00_设定.md` 的 initial_flags 登记）：

- `cleared_<area>`：每章净化完成后置 true（village/forest/catacomb/dungeon/forbidden/fort/castle）
- `relic_<n>`：每章拾取一枚遗物/石板碎片（8 枚，呼应「修复光耀守护宝具」，白巫女像文字 927-932）
- `chose_abyss`：终章关键选择

终章 c13 结构：

```
抵达边境之泉（bg spring，music awakening）
→ 芙莉蒂雅的幻影（对话剧情 769-812 引文）
→ 选项：
   A「净化她」                       → 结局 A（文本集 223-240）
   B「放弃净化，走向深渊最深处」       → set chose_abyss=true → 深渊（music boss_final
     boss_final_intro/outro）→ 结局 B（对话 869-924）
   C（仅当全部 relic_*=true 显示）「唤醒古代咒术，修复守护宝具」
     → when 八枚 relic → 结局 C 尾声（文本集 241-282，全员解放）
```

结局顺序建议：首次游玩自然落在 A；C 是全收集奖励路线（参考原作「尾声」定位）。
